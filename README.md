# astrology-icons-rashifal-icons

This repository contains a demo HTML with SVG sprites for 12 zodiac signs (राशि). Each sign has two variants included:

- Simple (filled circle symbol)
- Gradient (stroke-based symbol using linearGradient)

Files added:

- index.html — demo page showing both variants side-by-side (SEO-friendly meta tags in Hindi)
- assets/_icons.scss — SCSS source for styling the demo

You can open index.html in a browser to preview the icons. The SCSS file is the source used to style the demo; compile it if you want a separate CSS file.
